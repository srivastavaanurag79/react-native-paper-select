# Code of Conduct

## Our Commitment

The react-native-paper-select project is committed to providing a welcoming, respectful, and inclusive environment for everyone. We value constructive collaboration and encourage contributors of all experience levels to participate.

## Expected Behavior

When participating in this project, please:

- Be respectful and considerate.
- Be welcoming to new contributors.
- Provide constructive feedback and accept it gracefully.
- Focus discussions on improving the project.
- Help create a positive and collaborative community.

## Unacceptable Behavior

The following behaviors will not be tolerated:

- Harassment, discrimination, or hateful conduct.
- Personal attacks, insults, or trolling.
- Threatening or abusive language.
- Publishing someone else's private information without permission.
- Any conduct that would make others feel unsafe or unwelcome.

## Scope

This Code of Conduct applies to all project spaces, including:

- GitHub Issues
- Pull Requests
- Discussions
- Project documentation
- Any other official communication channels related to this project

## Enforcement

Project maintainers are responsible for enforcing this Code of Conduct. Reports of unacceptable behavior will be reviewed fairly and handled appropriately.

If you experience or witness unacceptable behavior, please open a private discussion with the maintainers or contact:

**Anurag Srivastava**

All reports will be handled confidentially whenever possible.

## Consequences

Maintainers may take any action they deem appropriate, including:

1. Warning the contributor.
2. Removing inappropriate comments or content.
3. Temporarily restricting participation.
4. Permanently banning repeat or severe offenders.
